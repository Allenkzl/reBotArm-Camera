# 拍摄工作台

当前升级分支：`feature/camera-photo-points`。真实机械臂默认 J1–J6，J7 不注册。

## 使用

1. 点击 **启动机械臂**，确认现场条件后进入可拖动录制模式。
2. 选择拍摄组。默认三组，每组四个动作块；可以增删和重命名组/动作。
3. 在动作块点击 **开始录制**，手动拖动机械臂，再点击 **停止录制**。重新录制覆盖对应动作前会确认；保存失败或越界时保留旧动作。
4. 录制成功保存后立即显示 **单独播放**；只要组内有已保存动作，启动状态下即可点击 **播放整组**。确认框列出将执行的动作及会跳过的空块；按列表顺序执行，四块都就绪时即 1→2→3→4。间隔默认五秒，可设 0–60 秒，最后一块后不再等待。
5. **停止播放 / 紧急停止**中止当前动作及后续动作，仍保持使能。完成后点击 **关闭机械臂**，返回 Home 零位，确认到达后失能；如果未可靠返回，会保持使能并报告异常，需人工处理。

「运行详情」提供关节状态、日志和额外的**紧急失能**。紧急失能会卸去支撑力，必须先人工支撑。状态显示来自服务确认；网页刷新、重新连接不会自动启动、播放或拍照。

## 蓝牙相机与拍照点

1. 唤醒相机，在左侧点击 **连接蓝牙相机**，等待“蓝牙已连接”。首次配对仍使用原快门网页。连接/断开相机不会启动机械臂。
2. 开始录制一个动作。到需要拍摄的位置，点击 **设置拍照点** 或按一下 **空格**。只记录下一条新鲜关节采样，不会当场拍照；可在列表中删除拍照点。
3. 点击 **停止录制**，保存轨迹及拍照点。单独播放和播放整组都会执行这些点；旧动作没有拍照点时照常播放，不要求相机连接。
4. 回放执行到拍照点对应采样后保持目标位置，立即发送一次快门，不检查拍照专用的到位精度或晃动；等待结果并停留后继续。拍照设置中的拍后停留默认1秒，可设0–10秒；与组内动作间隔独立。

空格仅在当前动作录制时有效；输入框、长按重复及组合键不记录。每个动作最多100个拍照点。含拍照点的回放会在运动前检查相机就绪；相机断连、机械臂常规跟踪异常或快门结果未知会中止后续点/动作，保持机械臂使能等待处理。未知结果不自动补拍，请先在相机核对照片，再显式重新连接。

2026-10-28按用户要求先验证流程，移除原2°到位及停稳等待门槛（包括等待快门结果/拍后停留时的2°门槛）。正常20°跟踪异常、反馈有效性、限位及停止功能保留。请在录制时于拍照位置留出足够静止时间，覆盖快门延迟；执行到采样点不代表实际位置精确到位，照片可能模糊或构图偏移。快门完成只表示指令写入完成，不保证照片已存卡；已经交给桥的快门不能撤回。首次建议只录一个动作、一个点，由操作者在旁验证，再试整组。

工作台通过同机 `http://127.0.0.1:8023` 调用现有 USB→ESP32→BLE 桥，固件仍为0.1.1。桥需独立运行并独占串口；不要同时启动第二个串口桥。启动工作台、刷新或重连均不自动拍照。`--dry-run` 使用模拟相机，不访问真实快门桥。

## 配置与数据

- 第一版额定相机总重 **950 g**，沿用此前 150 g 增量及估计质心。此模型尚未完成真实负载辨识，J3/J4 托举不足问题未由本次 UI 升级解决；不能只改克数就视为完成自动适配。
- 实机回放速度固定使用 25%。到动作起点采用平滑过渡，目标峰值速度不超过 0.15 rad/s；回放跟踪偏差超过 20° 会中止后续动作。
- 当前软件范围：J1 `[-55,55]°`、J2 `[-8,100]°`、J3 `[-1.5,80]°`、J4 `[-70,80]°`、J5 `[-35,35]°`、J6 `[-70,90]°`。这些是旁护测试范围，并非碰撞/线缆/物理安全校准。
- `logs/runs/shooting_groups.json`：组、块、间隔及轨迹槽位引用，原子写入。
- `logs/runs/camera_settings.json`：拍后停留配置；`photo_journal.jsonl`：发送前持久化的快门去重及结果记录，不应随意删除。
- `logs/runs/teach_trajectories.json`：原始角度/时间采样及可选 `photo_points`（ID、采样索引、时间及六关节位置）。首次升级把旧轨迹关联到第一组，不改写其字节。只有第一次创建组文件时迁移；删除组/块后重启不会重新导入。
- 删除组/块仅移除分组链接，原轨迹采样仍在原文件中供备份恢复；新录制不复用已保存历史槽位。上限 20 组、每组 20 块、400 个采样槽位。
- 原文件损坏会拒绝启动或保存，不用空默认数据覆盖。播放前预检全部选中的已保存动作；无效数值、时间顺序错误及越界会阻止整组开始。空块经明确提示后跳过；全部为空时不能播放。录制失败在对应块显示具体原因，失败重录会保留旧版本并在播放前明确提示。
