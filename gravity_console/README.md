# 拍摄工作台

当前升级分支：`feature/shooting-groups`。真实机械臂默认 J1–J6，J7 不注册。

## 使用

1. 点击 **启动机械臂**，确认现场条件后进入可拖动录制模式。
2. 选择拍摄组。默认三组，每组四个动作块；可以增删和重命名组/动作。
3. 在动作块点击 **录制动作**，手动拖动机械臂，再点击 **结束录制**。重新录制覆盖对应动作前会确认；保存失败或越界时保留旧动作。
4. 录制成功保存后立即显示 **单独播放**；只要组内有已保存动作，启动状态下即可点击 **播放整组**。确认框列出将执行的动作及会跳过的空块；按列表顺序执行，四块都就绪时即 1→2→3→4。间隔默认五秒，可设 0–60 秒，最后一块后不再等待。
5. **停止播放 / 紧急停止**中止当前动作及后续动作，仍保持使能。完成后点击 **关闭机械臂**，返回 Home 零位，确认到达后失能；如果未可靠返回，会保持使能并报告异常，需人工处理。

「运行详情」提供关节状态、日志和额外的**紧急失能**。紧急失能会卸去支撑力，必须先人工支撑。状态显示来自服务确认；网页刷新、重新连接不会自动启动、播放或拍照。

## 配置与数据

- 第一版额定相机总重 **950 g**，沿用此前 150 g 增量及估计质心。此模型尚未完成真实负载辨识，J3/J4 托举不足问题未由本次 UI 升级解决；不能只改克数就视为完成自动适配。
- 实机回放速度固定使用 25%。到动作起点采用平滑过渡，目标峰值速度不超过 0.15 rad/s；回放跟踪偏差超过 20° 会中止后续动作。
- 当前软件范围：J1 `[-55,55]°`、J2 `[-8,100]°`、J3 `[-1.5,80]°`、J4 `[-70,80]°`、J5 `[-35,35]°`、J6 `[-70,90]°`。这些是旁护测试范围，并非碰撞/线缆/物理安全校准。
- `logs/runs/shooting_groups.json`：组、块、间隔及轨迹槽位引用，原子写入。
- `logs/runs/teach_trajectories.json`：原始角度/时间采样。首次升级把旧轨迹关联到第一组，不改写其字节。只有第一次创建组文件时迁移；删除组/块后重启不会重新导入。
- 删除组/块仅移除分组链接，原轨迹采样仍在原文件中供备份恢复；新录制不复用已保存历史槽位。上限 20 组、每组 20 块、400 个采样槽位。
- 原文件损坏会拒绝启动或保存，不用空默认数据覆盖。播放前预检全部选中的已保存动作；无效数值、时间顺序错误及越界会阻止整组开始。空块经明确提示后跳过；全部为空时不能播放。录制失败在对应块显示具体原因，失败重录会保留旧版本并在播放前明确提示。

## 运行与验证

本机隔离模拟（不连接电机）：

```bash
python3 gravity_console/server.py --dry-run --port 8047 --log-dir /tmp/rebot-shooting-dryrun
```

远端沿用原服务启动参数，监听 `127.0.0.1:8012`，通过 SSH 转发访问。更新或重启前必须确认服务已失能、无电机连接、无录制/运动；不要在控制中直接杀进程。用户实机验收前，离线测试和网页可访问不代表运动精度或安全性已验证。

```bash
python3 -m unittest gravity_console.test_shooting_groups gravity_console.test_shooting_control -v

```
