# XIAO ESP32S3 Sense 佳能蓝牙快门第一版

## 已确认目标

用户已授权制作并烧录固件，在独立网页中配对 / 连接 EOS R6、显示真实连接状态、断开连接、清除配对以更换相机，以及手动触发单次快门。分支为 `feature/esp32-canon-shutter`。不涉及机械臂控制。

## 第一轮架构

浏览器 → 本机 Python HTTP 服务（仅监听 127.0.0.1）→ USB CDC → XIAO ESP32S3 → BLE → 相机。

先使用已连接的 USB，不依赖尚未提供的路由器配置。固件不启用板载摄像头。无线网页访问留待首轮 BLE 链路验证后扩展。使用 Arduino ESP32 3.3.8 自带 BLE 库、Preferences 和已有 ArduinoJson 7，不安装全局依赖。

## 状态与操作

- 启动后不自动配对、不自动拍照；只有用户按按钮时操作。
- 配对新相机：相机先进入“连接至无线遥控器 → 添加设备”，ESP32 扫描佳能遥控服务；只有一个候选时自动建立连接，多个候选时由用户选择。
- 连接：对已保存的相机地址重新连接；地址和地址类型一起保存。
- 只有 BLE 加密成功、身份写入成功且快门特征可用，才显示“已连接”。仅建立底层 BLE 链路不足以显示成功。
- 断开：断开 BLE，保留配对记录，不自动重连。
- 清除配对：断开并删除固件保存的相机地址和对应 BLE bond；相机端已有遥控记录需要按佳能菜单删除。
- 拍照：发送即时拍照按下与释放，避免保持快门；只显示指令发送结果，不声称照片已保存。用户应使用相机照片模式。
- 操作串行化，忙碌时拒绝新操作；持续报告状态。USB 丢失或状态过期时网页立即显示设备离线并禁用操作。
- 网页与固件均不在刷新、重启、重新连接时重放拍照命令。

## 验证与交付

编译目标 `esp32:esp32:XIAO_ESP32S3`。烧录前尽量备份原 8 MB flash；不将备份、密钥或生成的二进制提交 Git。烧录后核对固件标识与实时状态，打开实际网页。验证未连接时拍照被拒绝，以及搜索无相机时有明确结果。真实配对、对焦与存卡结果由用户在 R6 上参与验收，不能由编译或串口成功代替。

## 协议来源

- https://github.com/gkoh/furble 的 CanonEOSRemote（MIT）：服务 UUID、身份前缀 0x03、加密握手、快门按下 0x8c / 释放 0x0c。
- https://github.com/maxmacstn/ESP32-Canon-BLE-Remote：对 BR-E1 及佳能遥控驱动模式的交叉核对。
- https://cam.start.canon/en/C004/manual/html/UG-06_Network_0090.html ：EOS R6 配对和遥控驱动模式。

## 实施顺序

1. 读取设备身份和原 flash，创建独立分支。
2. 编写串口 JSON 协议、单任务 BLE 控制、配对持久化。
3. 编写本机串口桥和中文网页。
4. 编译；验证离线、超时和命令处理；烧录并核对设备启动。
5. 启动网页并进行浏览器验证，记录已验证范围及待实机验收项，提交本次文件。
