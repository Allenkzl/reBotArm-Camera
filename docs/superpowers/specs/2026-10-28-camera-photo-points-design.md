# 蓝牙快门与轨迹拍照点整合

用户确认规划并选择新分支 `feature/camera-photo-points`，基于 `feature/shooting-groups`。现有 XIAO canon-shutter-0.1.1 通过 USB 接在机械臂主机 `/dev/ttyACM0`，快门桥监听同机 `127.0.0.1:8023`；工作台后端通过本机 HTTP 接口调用，无需前端跨源访问或重烧固件。初始只读状态显示 ESP 在线、seeedr6 已连接；这不是本次触发拍照的验收。

## 操作

- 左栏在机械臂启动/关闭下加入连接蓝牙相机、断开连接及真实状态。连接不使能机械臂。首次配对仍可使用原快门页；不自动清除配对。
- 开始录制后显示停止录制、设置拍照点；空格与按钮调用同一接口。只在当前动作录制时有效，忽略长按重复、输入字段和修饰键，防止滚动/原按钮激活。
- 拍照点只记录、不在录制时发送快门。绑定下一条新鲜控制采样的 sample_index/t/q_rad 和唯一 ID；最多100点/动作，可删除。保存附在原轨迹的可选 photo_points 字段；旧动作默认空列表。
- 组播放与单动作播放均执行拍照点；无拍照点的旧动作不要求相机在线。含点的动作在任何运动前检查相机就绪。拍后停留默认1秒，可在左栏调0–10秒，与动作间隔分开。

## 回放

到达采样索引时保持该关节目标，等待实际反馈到位并稳定，再发一次快门，等待准确命令ID对应结果，拍后停留，再继续轨迹。暂停耗时加入播放时钟，后续采样不追赶。期间持续下发位置保持并检查停止/反馈，不在控制线程执行阻塞HTTP。

初始停稳参数：各关节误差不超过2°，连续0.5秒窗口变化不超过0.3°，最长等待10秒。参数尚未实机验收，不宣称这等于成像无抖动/绝对TCP精度；未到位就中止，不能静默放宽阈值或继续拍。

快门请求使用每次回放唯一 run/slot/point key；发送意图先 fsync 记录。相同key禁止重发；丢失响应、超时、断连、USB恢复和刷新均不自动补拍。结果未知时中止后续点/动作，人工核对后显式重新连接解除暂停。已经交给快门桥的指令无法撤回，停止不表示能取消在途快门。成功只表示快门写入完成，不等于照片已存卡。

## 验证与部署

先做本机/模拟桥和离线控制测试：状态读取不触发命令；拍照点绑定/保存/重载；键盘和按钮一致；到位、稳定、超时、取消；命令ID、去重和未知结果；暂停后时间正确；旧动作兼容。所有自动测试使用假HTTP/模拟设备，禁止真实运动或触发快门。

远端先校验原代码和当前失能状态，备份轨迹与源文件，再部署工作台模块。现有快门桥和ESP固件保持原样，不重启USB服务。由用户先验收相机按钮，再录一个动作/一个点并人工回放，最后再验收整组。保持额定950g及现有控制/角度参数，不合并/推送。
